# Обложка

Основа: исследование (2.1, 2.2, 7) и правила дизайна автора.
- Шортс в ленте стартует с ПЕРВОГО КАДРА: он и есть обложка. Поэтому первый кадр = готовый результат + метка 2-4 слова.
- Отдельная обложка нужна для канала, поиска, шеринга: `cover DIR`.
- Картинку может дать модель, пользователь (`--image`) или честный кадр из ролика (всегда есть: движок сохраняет
  чистые кадры центра без субтитров в `cover/candidates/`). **Текст всегда рисует код** шрифтом бренда.
- 3 варианта (`punch` плашка-акцент, `minimal` чёрный воздух + окно кадра, `outline` кадр + обводка) x 1280x720 и 1080x1920,
  плюс превью 320 px. Текст на противоположной стороне от главного объекта (по центру масс контуров).
- Проверки: 3-5 слов, читается на 320 px (высота букв от 14 px), контраст текста от 4.5:1 по реальным пикселям,
  16:9 без текста в правом нижнем углу (там время), 9:16 внутри safe-зоны, без градиента, силуэт (серый + размытие).
- Генератор картинок: `OPENAI_API_KEY` (gpt-image-1) или `GEMINI_API_KEY` (gemini-2.5-flash-image), `SHORTS_IMAGE_PROVIDER`
  для выбора или `none`. Код вызова не проверен без ключа: при ошибке движок честно откатывается на кадры.
- Нет генератора: отдай `cover/prompt.md` (сцена, трети, палитра, что НЕ рисовать, форматы) и попроси картинку.
- Нельзя: неон, свечение, фиолетово-синие градиенты, кинематографичные клише, коллаж, чужой бренд или лицо.
