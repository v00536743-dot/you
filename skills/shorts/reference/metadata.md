## Правила (скрипт проверяет)
- 5-7 названий, громкость 1 (капс, эмодзи, цифра, крупное обещание) ... 5 (поисковая фраза, без капса и эмодзи).
- До 100 знаков вместе с хэштегами, эмодзи максимум одно, капс только в вариантах 1-2, 3-6 хэштегов, `#shorts` для Shorts.
- Все честные: обещают то, что есть в ролике. Ключевое в начале. Для каждого пометка: поиск или интрига, и почему.
- Описание (ОДНО): до 3 хэштегов (покажутся над названием) / 1-2 предложения / один призыв / ссылки пользователя /
  пустая строка / нижние хэштеги. Всего около 15 уникальных хэштегов, больше 60 = YouTube игнорирует все.
- Ссылки только из настроек и плана. Нет ссылок = их нет в описании (скрипт предупредит).
- Закреп: 3 строки (польза, ссылка, вопрос). TikTok: подпись + до 5 хэштегов.
- Нет длинных тире. Язык = язык ролика.
- Рекомендуй один вариант одной строкой. Для ленты Shorts обычно интрига (2-3), для поиска и канала спокойный (4-5).
- Запомни выбор пользователя (`remember_choice("chosen_title", ...)`): следующие названия подстраивай под него.
