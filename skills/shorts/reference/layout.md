# Раскладка кадра 1080x1920

| Режим `layout.mode` | Панели |
|---|---|
| `three` | верх (до 20%) + центр (от 55%) + низ (до 20%) |
| `top_center` | верх + центр |
| `center_bottom` | центр + низ |
| `center_only` | только центр (эдиты, нарезки) |

- Верх: **живое видео с движением** (свой геймплей, записи проектов, кадры исходника), без пустых мест.
  Источник: файл видео (зацикливается), `html:файл.html` (снимается кадр за кадром) или своё
  `assets/footage/own-game-loop.mp4`. `color:#hex` = пустая панель, QA провалит.
- Центр: главное (сайт, HTML-сцена, эпизод). Всегда от 55% высоты.
- Низ: фирменная полоса (логотип словом, ссылка, ник). Помни: в Shorts нижние 672 px закрыты интерфейсом,
  поэтому низ это подпись бренда, а **реклама живёт во вспышках из центра** (`reference/qr.md`).
- Сетка 8 px, одна кривая плавности (ease-out cubic) на весь ролик.

## Рабочая (safe) зона
`schema/safe_zones.json`, для нескольких платформ берётся пересечение (самое строгое):

| Платформа | верх | низ | лево | право | доп. | источник |
|---|---|---|---|---|---|---|
| YouTube Shorts | 288 | 672 | 48 | 192 | - | Google Ads, шаблон вертикального видео |
| TikTok | 240 | 660 | 120 | 120 | колонка кнопок x 780-1080 от y 840 | TikTok Ads, шаблон In-Feed (720x1280, spellfestivalpen1.5) |
| Reels | 269 | 672 | 65 | 65 | - | Meta Ads Guide: 14% / 35% / 6% |

Внутри зоны: метка-заголовок сцены сверху, вспышки CTA в середине, субтитры в нижней трети.
Для TikTok полоса субтитров и вспышек сдвинута левее колонки кнопок автоматически.
