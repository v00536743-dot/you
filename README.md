# Начерталка к зачёту: метод прямоугольного треугольника

Один файл — `index.html`. Скачай его и открой в любом браузере (на компьютере или телефоне). Интернет не нужен.

## Что внутри

Экран поделён на три части:

1. **Дано / Найти** — как оформляем в тетради (по образцу практики 2).
2. **Чертёж** — строится по шагам: на каждом шаге появляются только новые линии.
3. **Алгоритм** — строки появляются по одной, под текущей строкой коротко объяснено, *почему* линия идёт именно туда.

Вкладки:

- **1 · Метод Δ** — откуда берётся прямоугольный треугольник (сначала в пространстве, потом на чертеже) и правило «какой катет брать».
- **2 · Нарешка** — все варианты ДЗ 1-01…1-28 (★ 1-03 — моё ДЗ) и задача 2 из билета 15, который был на зачёте.
  - Тип 1: найти |AB| и углы.
  - Тип 2: дан угол → достроить проекцию, сколько решений.
  - Тип 3: дана длина → достроить проекцию, найти угол, сколько решений.
- **3 · Задача 1: прямые** — 7 видов прямых: признак на КЧ, где натуральная величина, пространственная модель, что записать. Плюс тренажёр «угадай прямую».
- **4 · Зачёт** — что будет на зачёте, план подготовки с галочками и образец оформления.

Никаких вычислений: длины переносим циркулем, |AB| меряем линейкой, углы — транспортиром.
Координаты вариантов сняты с фото листа приблизительно, поэтому форма чертежа похожа на лист, но размеры — нет.

Управление: «Дальше →» или стрелки ← → на клавиатуре; клик по строке алгоритма возвращает к этому шагу.
