# Копия движка SHORTS

Здесь будет копия движка из чата SHORTS (папка `skills/shorts/` в репозитории `v00536743-dot/you`).
Руками не правим: её кладёт и перезаписывает `python3 tools/sync_engine.py --from ... --ref ...`.
Какой это коммит, написано в `viora-shorts/ENGINE_VERSION`.

Пока движка нет, ферма собирает всё до плана включительно, а рендер и QA проверяются на заглушке
`viora-shorts/tests/fake_engine.py`. В отчёте ролика это написано прямо.
