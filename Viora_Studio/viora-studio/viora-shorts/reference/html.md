# Адаптер html: ролик про HTML-файл

Автор кидает один HTML-файл (игра, анимация, «фильм» в одном файле) и просит рассказать
про него. Примеры автора: фильм про «Титаник» из одного файла на 896 КБ
(https://www.youtube.com/watch?v=-0_vkt9AL5A) и игровая карта с оружием на three.js
(https://www.youtube.com/watch?v=6p_3VtHbeow).

## Команда

```bash
python3 tools/reel.py farm film.html --speed "0-5:1,5-20:2.5,20-24:0.5" --sound page
python3 tools/reel.py farm film.html --script script.json   # твой рассказ по главам
```

## Что код читает из файла (`viora-shorts/vshorts/html_adapter.py`)

| Что | Откуда | Зачем |
|---|---|---|
| Главы | `data-scene="Название"`, `data-t`, `data-end`, `data-best` | сцены плана и реплики |
| Длина | `data-duration` или `window.__duration` | таймлайн |
| Детерминированный захват | есть `window.__seek(t)` | кадр как функция времени, без рывков |
| Звук страницы | `AudioContext`, `<audio>`, `<video>` | выбор способа записи |
| Старт по клику | «click to start», `resume()` | движок кликает перед записью |
| Клавиши | `e.key === "w"` и подобные | для игры: нажатия каждые 2-3 с |
| Сеть | `<script src="https://...">` | предупредить: офлайн не снимется |

Если в файле нет `data-scene`, глав нет: таймлайн режется поровну, рассказ пишешь ты.
Попроси автора (или сам добавь в копию файла) метки `data-scene`, это делает ролик точнее.

## Два способа снять страницу

| Способ | Когда | Плюс | Минус |
|---|---|---|---|
| deterministic | есть `__seek(t)` или звук не нужен | гладко, кадр в кадр | звук страницы не записать, вместо него SFX и музыка |
| realtime | `--sound page` и у страницы есть свой звук | слышно саму страницу | возможны рывки, ретайм потом |

Так же работают HyperFrames (кадр это чистая функция времени, `seek` на каждый кадр,
ожидание шрифтов перед снимком) и подход Replit (подмена часов `Date`, `performance.now`,
`requestAnimationFrame`, перехват `AudioBufferSourceNode.start` и `HTMLAudioElement.play`).
Источники в `docs/research-log.md`.

## Скорость

`--speed "от-до:скорость,..."` в секундах исходника. Скучное ускоряем 1.5-3x, ключевой
момент замедляем 0.3-0.6x (COMMON.md раздел 3). Пределы 0.25-4: медленнее рвётся звук
(atempo), быстрее глаз ничего не видит. Звук ретаймится вместе с картинкой.

## Звук

`--sound page` звук самой страницы, `sfx` наши щелчки и свуши, `music` трек из настроек,
`mute` без звука (только голос). Выбор запоминается: `reel.py prefs set html.sound=page`.

## Первый кадр

Крючок показывает самый зрелищный кусок: глава с `data-best="true"`, иначе середина.
Реплика крючка: «Это не видео. Это один HTML-файл на N КБ», цифру даёт код из размера файла.

## Чего не делаем

- Не говорим «без движка», если внутри three.js: это тоже движок.
- Не обещаем «за 5 минут», если автор не говорил, сколько делал.
- Не правим исходный файл автора: метки ставим только в копию.
