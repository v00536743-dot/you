# QA перед выдачей ролика

Ролик без пройденного QA автору не отдаём. Ферма пишет чек-лист в report.md сама.
Здесь, кто что проверяет и что делать руками.

## Три слоя проверки

| Слой | Кто | Что |
|---|---|---|
| До рендера | наш код | сценарий (`viora-shorts/vshorts/script.py`), план (`viora-shorts/vshorts/schema.py`: схема и правила COMMON.md), упаковка (`viora-shorts/vshorts/metalint.py`), анонс (`lint_post.py --strict`), обложки (`viora-shorts/vshorts/cover.py`) |
| После рендера | движок SHORTS | формат, первый кадр, движение, safe zone по пикселям, QR декодером, субтитры, громкость, анти-слоп по кадрам |
| Глазами | модель | контактный лист, пересказ без звука, обещание выполнено, профиль канала, пометка ИИ |

## Правила плана, которые ловит код до рендера

| Код | Правило |
|---|---|
| E-CENTER | центр меньше 55% высоты |
| E-TOP-EMPTY, E-TOP-SLOP | верхняя панель без видео или с абстрактным фоном |
| E-CTA-MANY, E-CTA-LEN, E-CTA-OVERLAP | больше трёх вспышек, длина не 1.5-3 с, наложение |
| E-QR-MISSING, E-QR-URL, E-QR-NO-TEXT | QR включён, но нет; ведёт не туда; нет текстовой ссылки рядом |
| W-QR-WHEN, W-HANDLE-WHEN | QR не в последних 3-4 с; ник не на 40-60% |
| E-COLORS, E-MONO-COLOR, E-COLOR-HEX | больше трёх цветов; цвет в mono; кривой цвет |
| E-FONT-DEFAULT | DejaVu, Arial и прочие шрифты по умолчанию |
| E-CAPTION-WORDS, W-CAPTIONS-OFF | порция субтитров больше трёх слов; субтитры выключены |
| E-LUFS | громкость не около -14 |
| W-STILL | в сцене дольше 3 с без события |
| W-WHY | у сцены нет поля why |
| E-DURATION | оценка длиннее цели |
| E-DASH | длинное тире где угодно в плане |

## Чек-лист 20 пунктов (исследование, раздел 9)

В report.md у каждого пункта: кто проверил (auto, engine, manual) и итог.
«движок не проверял (заглушка)» значит, что рендер делала `viora-shorts/tests/fake_engine.py`:
видео нет, пиксели никто не смотрел. Так и пишешь автору.

## Что делаешь руками

1. Контактный лист (2 кадра в секунду) от движка: нет пустых кадров, текст не обрезан,
   ничего не лезет под интерфейс. Пиши, какие кадры посмотрел.
2. Пересказ без звука: по картинке и субтитрам. Не получается пересказать: правь текст на экране.
3. Обещание: всё, что сказано в крючке и названии, есть в ролике.
4. Профиль канала: аватар, шапка, описание с одной ссылкой, закреплённый ролик. Напомни автору.
5. Пометка «изменённый или синтетический контент»: озвучка синтезатором и запись сайтов обычно
   её не требуют, реалистичные подделки людей и событий требуют. Напомни проверить при загрузке.

## Различимость (пункт 20)

YouTube с 15.07.2025 режет монетизацию за «массовый» однотипный контент. Ферма сравнивает
название нового ролика с журналом: похожесть от 70% это «НЕТ». Меняй крючок, первый кадр,
длину, а не только цифру.
