# Ролик за одну команду (тир для слабых моделей)

Ты читаешь этот файл и больше ничего про ролики читать не надо.

## Автор написал «с этим делай ролик, а не пост»

```bash
python3 tools/reel.py farm файл_или_текст
```

Скрипт сам проверит сайты, напишет каркас сценария, соберёт план, отдаст его движку,
сделает названия, описание, закреп, обложки и анонс. Всё ляжет в одну папку.

## Скрипт вышел с кодом 3

Он напечатал вопросы. Отправь их автору ОДНИМ сообщением, как есть.
Ответы запиши так, по одному на ключ:

```bash
python3 tools/reel.py prefs set language=ru platforms=youtube_shorts,tiktok layout=three qr=да brand=viora voice=male sources=site
```

Автор сказал «потом»: `python3 tools/reel.py farm файл --defaults`.

## Что отдать автору

1. Открой report.md в папке пакета и перескажи итог одной строкой.
2. Дай рекомендованное название и список остальных из titles.md.
3. Дай описание из description.txt, закреп из pinned.txt, подпись из tiktok.txt.
4. Дай анонс из announce.txt. Он уже прошёл линтер постов. Вместо ссылки на ролик там
   метка PASTE_VIDEO_URL: когда автор выложит ролик, запусти
   `python3 tools/reel.py announce папка --video-url ссылка`.
5. Обложки: файлы `cover-*.png` или промпт из cover-prompt.txt.
6. Последней строкой перешли напоминание из отчёта, если оно есть («Не заполнено: ...»).

## Четыре правила

1. НЕ ВЫДУМЫВАЙ ССЫЛКИ И ЦИФРЫ. Сайт без адреса: спроси адрес одной строкой.
2. ЗАКРЫТЫЙ САЙТ НЕ ОБХОДИМ. Скрипт его выкинул, так и скажи автору.
3. ДВИЖКА НЕТ: в отчёте «ПЛАН ГОТОВ, ВИДЕО НЕТ». Так и скажи автору: видео не собрано.
   «Готово» говоришь только когда в отчёте «ГОТОВО».
4. Длинных тире нет нигде. Только дефис.

## Если скрипт ответил ошибкой

Он печатает причину и что править. Ошибка в сценарии: открой script.json в папке,
поправь реплику и запусти `python3 tools/reel.py farm файл --script путь/script.json`.
