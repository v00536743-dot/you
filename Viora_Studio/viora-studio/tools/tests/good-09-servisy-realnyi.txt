5 полезных сайтов и скиллов.

1. [Emotion Direction](https://example.com/emotion). Готовые промпты для эмоций в видео. Жесты, поза, мимика, направление взгляда и интенсивность уже расписаны. Для каждого промпта есть пример генерации. Подходит для любых нейронок.

2. [AI UI Design от Google](https://example.com/uidesign).
- Гайд по созданию интерфейсов через AI Studio. Внутри 8 советов, примеры и готовые промпты. Описываем идею обычным текстом, а ИИ собирает код, рабочий интерфейс и превью.

3. [Photon](https://example.com/photon).
- Бесплатный аналог Photoshop сделанный с помощью GPT-6 Astra. Внутри основные функции графического редактора и нативная поддержка Linux.
Проект пока сырой. На тяжёлых файлах могут быть баги.
[Как его создали](https://example.com/how).

4. [Security Audit Skill от Cloudflare](https://example.com/audit).
- Папка с инструкциями для агента, который проводит аудит безопасности в шесть этапов. В конце пользователь получает готовый отчёт с найденными проблемами.

5. [Inspo](https://example.com/inspo).
- MCP-сервер для создания дизайна. Ищет референсы среди 800+ сайтов и передаёт их Claude Code, Codex или OpenCode.
Можно попросить агента найти примеры под конкретный экран, стиль или продукт, а затем собрать свой интерфейс на их основе. Проект бесплатный и с открытым исходным кодом.
Установка: npx inspo-mcp install

Простыми словами: MCP это переходник, через который Claude или Codex видят чужой сервис. Ставим одну команду и агент сам тащит референсы в наш проект.
