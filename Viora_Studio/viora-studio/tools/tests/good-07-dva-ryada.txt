Ку, охотники за халявой.

Собрал 4 сервиса, которые робят без карты. Один закроют 30 сентября.

1. [Emotion Direction](https://example.com/emotion).
- Готовые промпты для эмоций в видео: жесты, поза, взгляд. К каждому есть пример генерации.

2. [AI UI Design](https://example.com/uidesign).
- Гайд по интерфейсам через AI Studio: 8 советов и промпты. Описываем идею текстом, код собирает нейронка.
- С российских адресов страница не открывается, я заходил через VPN.

3. [Photon](https://example.com/photon).
- Бесплатный аналог фотошопа на GPT-6, нативно тянет Linux. [Как его собирали](https://example.com/how).

4. [Inspo](https://example.com/inspo).
- Ищет референсы по 800 сайтам и отдаёт их в Codex. Ставится командой `npx inspo-mcp install`.

ВАЖНО! Третий пункт сырой: на файле в 40 МБ у меня вылетел с ошибкой.

Из минусов: лимиты крутят без предупреждения.

Гонял все четыре вечером, два завелись с первого раза.

Перешли тому, кто до сих пор рисует превью руками.
