3 сервиса, которые робят без карты. Первый закрывают 30 сентября.

1. [Emotion Direction](https://example.com/emotion).
- Готовые промпты для эмоций в видео: жесты, поза, взгляд. К каждому есть пример генерации, забрать можно до 30 сентября. Регистрация по почте, карту не просят.

2. [Photon](https://example.com/photon).
- Бесплатный аналог фотошопа на GPT-6, нативно тянет Linux. Проект пока сырой, на тяжёлых файлах лагает.

3. [Inspo](https://example.com/inspo).
- Ищет референсы по 800 сайтам и отдаёт их в Codex.
Установка: npx inspo-mcp install

Простыми словами: MCP это переходник, через который Codex видит чужой сервис. Поставил одну команду и агент сам тащит примеры в проект.

ВАЖНО! Второй при первом запуске просит привязать карту для проверки: отвязывается в тот же день.

Пожалуй, третий тут самый полезный: остальные два решают одну задачу, а он экономит целый вечер.

Налетайте, пока дают.
