# Роутер: что читать и когда остановиться

Скилл большой. Целиком его читать не надо никогда и никому.
Задача этого файла: ты открываешь один файл вместо тринадцати.

## Бюджет контекста по тирам

| Тир | Кому | Файлы | Объём |
|---|---|---|---|
| 0 | слабые и быстрые модели, автодополнение, маленькое окно | `QUICKCARD.txt` | 24 КБ |
| 1 | обычная работа над постом | `SKILL.md` | 33 КБ |
| 2 | сложная задача | `SKILL.md` плюс РОВНО ОДИН файл по таблице ниже | плюс 5-23 КБ |
| 3 | среда без файловой системы | `PROMPT-CORE.txt` или `PROMPT-FULL.txt` | 41 / 264 КБ |

Правило тира 2: один файл на одну задачу. Два файла читаются только тогда,
когда первый прямо сказал «смотри такой-то файл».

## Стоп-слова: когда ЧИТАТЬ НЕ НАДО

1. Просят поменять одну строку в готовом посте. Меняем и гоняем линтер.
2. Линтер вернул конкретный код и подсказку. Правим по подсказке, без теории.
3. Нужна цифра или ссылка. Гоняем `tools/research.py`, а не читаем reference.
4. Автор сказал «быстро» или «коротко». Работаем по QUICKCARD и линтеру.

## Главный принцип версии 5

Скрипты держат правила, модель держит вкус.

Слабая модель не удержит двадцать правил в голове, но вполне умеет запустить
команду и починить то, на что ей указали пальцем. Поэтому всё, что можно
проверить кодом, проверяет код:

| Скрипт | Что снимает с модели |
|---|---|
| `tools/viora.py` | одна точка входа: `route` даёт план, `hook` даёт первую строку, `ship` проверяет всё сразу |
| `tools/lint_post.py` | правила вёрстки, голоса, ритма и слопа, режим анонса, автоправка по `--fix` |
| `tools/lint_article.py` | статья для telegra.ph: подпись V.Studio, слитные абзацы, ликбез, хвосты |
| `tools/score_post.py` | оценка 0-100 на цифрах канала, секция ДУША и три конкретные правки |
| `tools/memory.py` | приветствия командой greet, лог постов и замеры без ручной писанины |
| `tools/split_post.py` | решение «резать или нет» и сам разрез |
| `tools/lint_chat.py` | следит за твоими же ответами в чате |
| `tools/research.py` | выбор источника, цепочка повторов, сжатие вывода, режим `--explain` |
| `tools/search.py` | пять движков, шесть источников, профили пост и код, кэш |
| `tools/ai.py` | ключ, модель, голос канала, чистка слопа на выходе |
| `tools/post.py` | факты, текст, автоправка, оценка в одной команде |
| `tools/watch.py` | транскрипт, кадры, бюджет контекста |
| `tools/tg.py` | мост с Избранным: очередь заявок, гейт линтера, тексты для автора, outbox к сторожу |
| `tools/tg_watch.py` | сторож: одно соединение, вложения, мозг, расписание, автоответы на бытовое |
| `tools/agent.py` | подписочный CLI агента как мозг: claude, codex, agy, gemini без ключей |
| `tools/life.py` | комп, погода, утро одной строкой, без модели |
| `tools/schedule.py` | напоминания и что пора выполнить в эту минуту |
| `tools/autostart.py` | автозапуск сторожа при входе в систему |
| `tools/build_prompt.py` | сборка ядра из одного источника |
| `tools/reel.py` | ролик одной командой: сырьё, сайты, сценарий, план, движок, упаковка, анонс, замеры |
| `tools/lint_video_meta.py` | названия, описание, закреп и подпись TikTok по шаблону автора |
| `tools/sync_engine.py` | вшивает движок SHORTS и фиксирует его коммит |

Если скрипт недоступен (нет питона, нет шелла, чат без файлов): работаем по
`QUICKCARD.txt` или `PROMPT-CORE.txt` и один раз говорим автору одной строкой,
что линтер не запустился и пост не проверен машиной.
